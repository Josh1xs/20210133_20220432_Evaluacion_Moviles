Funcionalidades del Sistema

La aplicación cuenta con las siguientes características:

Inicio de sesión (Login): Autenticación de usuarios registrados.

Registro de usuarios: Creación de nuevas cuentas en el sistema.

Perfil de usuario: Visualización de la información asociada a la cuenta del usuario.

Edición de perfil: Actualización y modificación de la información personal del usuario.
